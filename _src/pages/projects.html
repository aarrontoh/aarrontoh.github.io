Ahbot: a personal finance operating system

A system I designed, built and run for my own household. It keeps track of spending and investments automatically, and answers questions through a chat assistant and an installable app that share one engine. It runs itself, and only asks me for something when a human is genuinely needed.

  • Deterministic by design: every number comes from tested code, never from guesswork. AI only helps with wording, and code checks its output before anyone sees it.
  • Around 5,000 automated tests, most of them written from a real failure the system once had, with the reasoning behind the fix.
  • Runs on a schedule without me, and tells me straight away if any part of it stops working.
  • Built security-first, with a threat model behind every feature. The details stay private, as they should.
