Red Team DevOps, Adversary Simulation

Jun 2025 – Mar 2026

I built the engineering behind adversary simulation: a platform that runs real-world attacker techniques against live defences, safely and on demand, so blue teams can prove what they would and wouldn't catch.

  • Designed and built an adversary-emulation platform that executes MITRE ATT&CK techniques in a controlled, repeatable way for purple-team exercises.
  • Wrote a library of attacker techniques in C and C++, each mapped to ATT&CK, including Beacon Object Files for fileless, in-memory execution.
  • Engineered a GitLab CI/CD pipeline that compiles every technique for Windows and Linux automatically, with Docker-based cross-platform builds and a catalogue of versioned artifacts.
  • Built an offline execution engine that sequences techniques step by step (run, wait, log) for isolated environments.
  • Worked with security engineers to measure detection coverage against known attack paths and close the gaps.
void adversary_simulation(range_t *range)
{
  for ( ttp_t *t = mitre_attack; t; t = t->next )
  {
    binary_t *b = gitlab_ci_build(t, WIN64 | LINUX); // C/C++, BOFs
    catalogue_add(b);                         // versioned
  }
  plan_t *p = sequence(range->scenario);     // offline-capable
  while ( (step = next(p)) )
  {
    run(step); wait(step->delay); log(step);
  }
  coverage_t c = validate_detections(range->blue_team);
  close_gaps(&c);                            // the point of it all
}
